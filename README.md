# Joshua Garrison

I design software systems and direct AI coding agents to build them.
I don't hand-write code. My job is the architecture, the specs, the
review, and keeping agents on track until the thing actually ships.

My background is 13 years in construction services, so most of what I
build is for the business side of that world: job costing, billing,
and the operations work in between.

## What I'm building

- **[Pitbull](https://github.com/jgarrison929/pitbull)**: a multi-module
  construction ERP (job costing, WIP, AIA billing, AP/AR/GL) on
  C#/.NET, Next.js, and PostgreSQL. There's a
  [live demo](https://demo.pcserp.app) with no signup, and the repo
  includes the `AGENTS.md` and `CLAUDE.md` files the agents work from.
- **[river-runtime](https://github.com/jgarrison929/river-runtime)**: an
  earlier agent runtime I designed, with tiered memory, an MCP server,
  and sub-agent dispatch. It's no longer active, but it stays up as a
  reference for the design.

## How I work

I write the spec, break it into tasks, hand them to AI agents, and
review what comes back against tests and CI. I've also written up
[how I coordinate multiple AI agents](https://gist.github.com/jgarrison929/95b46194c52196724ed485dbc917e9c3) and
[the memory problem](https://gist.github.com/jgarrison929/2e848e7ae79878e0fe254c30e471d12a).
